# MY INSTAGRAM STUDIO

## 인스타그램 게시글·카드뉴스 전용 사진 편집 프로그램 기획서

## 1. 프로젝트 개요

### 목적

인스타그램에 게시할 정보·사건·상식·동물·유머 콘텐츠를 쉽고 빠르게 제작할
수 있는 개인용 사진 편집 프로그램을 만든다.

보내준 참고 이미지처럼 사진 하단에 어두운 그라데이션 영역을 만들고, 그
위에 눈에 잘 띄는 제목을 배치하는 카드형 게시물 제작을 핵심 목표로 한다.

### 핵심 개발 방향

-   **AI API를 연결하지 않는 독립형 편집기**로 개발한다.
-   사진 편집과 디자인 배치는 일반적인 프론트엔드 이미지 처리 기술로
    구현한다.
-   제목 추천은 AI 생성 대신 미리 준비한 문구 라이브러리와 템플릿을
    활용한다.
-   우선 개인이 반복해서 사용하는 데 필요한 기능부터 구현하고, 이후
    기능을 확장한다.

## 2. 주요 사용자 흐름

1.  프로그램을 실행한다.
2.  JPG 또는 PNG 사진을 업로드한다.
3.  게시물 비율을 선택한다.
4.  사진 위치와 크기를 조절한다.
5.  하단 그라데이션·블러 효과를 적용한다.
6.  제목을 직접 입력하거나 문구 라이브러리에서 추천 문구를 선택한다.
7.  글꼴, 크기, 색상, 정렬, 줄 간격 등을 조절한다.
8.  편집 결과를 미리 확인한다.
9.  PNG 또는 JPG 파일로 저장한다.

## 3. 필수 기능

### 3.1 사진 편집

-   JPG·PNG 이미지 업로드
-   사진 자르기 및 비율 변경
-   확대·축소 및 위치 이동
-   밝기·대비 조절(확장 기능)
-   원본 사진을 유지한 상태에서 편집

### 3.2 하단 디자인 효과

-   사진 하단 검은색 그라데이션 적용
-   그라데이션의 높이와 농도 조절
-   블러 또는 부드러운 어두움 효과
-   제목이 잘 보이도록 자동 가독성 확보
-   효과 적용 전후 미리보기

### 3.3 제목 및 텍스트 편집

-   제목 직접 입력
-   글꼴 및 굵기 변경
-   글자 크기·색상 조절
-   가운데·왼쪽·오른쪽 정렬
-   줄 간격 및 자간 조절
-   외곽선과 그림자 효과
-   텍스트 위치 이동
-   자동 줄바꿈 및 줄 수 조절

### 3.4 문구 추천 라이브러리

AI API 없이 사전에 등록한 문구를 분류해 추천한다.

추천 카테고리: - 자극적·호기심 유발형 - 재미·유머형 - 정보 전달형 -
뉴스·사건형 - 동물·과학·역사 등 주제별 문구

예시 문구: - "알고 보면 정말 놀라운 이야기" - "보고도 믿기 힘든 상황" -
"우리가 몰랐던 흥미로운 사실" - "지금 가장 뜨거운 화제"

사용자는 추천 문구를 선택한 뒤 자유롭게 수정할 수 있어야 한다.

**제약 사항:** 문구 라이브러리는 사진 내용을 스스로 분석하지 않는다.
따라서 사진에 정확히 맞는 새로운 제목을 자동으로 만들어 주는 AI 기능과는
차이가 있다.

### 3.5 템플릿 및 저장

-   자주 쓰는 글꼴·색상·그라데이션 설정 저장
-   디자인 템플릿 저장 및 재사용
-   PNG·JPG 내보내기
-   고해상도 출력
-   향후 여러 장 일괄 제작 기능 확장

## 4. AI API를 사용하지 않는 이유와 장단점

### 장점

-   외부 AI API 사용료가 발생하지 않음
-   API 키 관리와 외부 서비스 의존성이 없음
-   사진 편집 기능을 안정적으로 반복 사용 가능
-   인터넷 연결 없이도 작동하도록 설계 가능
-   사용자가 원하는 디자인 규칙을 일관되게 유지 가능

### 단점 및 한계

-   사진의 내용을 자동으로 이해할 수 없음
-   사진에 딱 맞는 새로운 제목을 즉석에서 생성하기 어려움
-   문구 추천은 사전에 준비한 데이터 범위 안에서 이루어짐

### 보완 방법

-   문구를 충분히 많이 준비하고 주제·말투별로 분류한다.
-   사용자가 사진 주제나 핵심 단어를 직접 입력할 수 있게 한다.
-   입력한 주제와 문구 카테고리를 조합해 추천 범위를 좁힌다.
-   제목은 언제든 직접 수정할 수 있게 한다.

## 6. 단계별 개발 계획

### 1단계 --- 기본 편집기

-   사진 업로드
-   사진 미리보기
-   게시물 비율 선택
-   사진 확대·축소 및 위치 조절
-   하단 검은색 그라데이션 적용
-   PNG 저장

### 2단계 --- 텍스트 편집

-   제목 입력
-   글꼴·크기·색상·굵기 변경
-   정렬·줄 간격·외곽선·그림자
-   텍스트 위치 조절 및 자동 줄바꿈

### 3단계 --- 문구 추천

-   문구 카테고리 선택
-   추천 문구 표시
-   문구 선택 및 편집
-   사용자 문구 추가 및 관리

### 4단계 --- 템플릿 기능

-   편집 설정 저장
-   저장한 템플릿 불러오기
-   여러 게시물에 동일한 디자인 적용

### 5단계 --- 확장 기능

-   여러 장 일괄 제작
-   게시물별 번호·카테고리 표시
-   추가 사진 보정 기능
-   다양한 인스타그램 게시물 규격 지원

## 7. 우선 개발 범위(MVP)

첫 버전에서는 아래 기능만 완성하는 것을 목표로 한다.

-   [ ] 사진 업로드
-   [ ] 사진 비율 및 위치 조절
-   [ ] 하단 검은색 그라데이션
-   [ ] 제목 입력
-   [ ] 글꼴·크기·색상·정렬 조절
-   [ ] 결과 미리보기
-   [ ] PNG 파일 저장

첫 버전의 핵심 성공 기준은 **사진 한 장을 업로드한 뒤 하단 디자인과
제목을 편집해 원하는 카드형 게시물 이미지로 저장할 수 있는 것**이다.

## 8. 최종 개발 원칙

1.  포토샵 전체를 복제하려 하지 않는다.
2.  인스타그램 카드뉴스 제작에 자주 쓰는 기능에 집중한다.
3.  사진 원본과 편집 요소를 분리해 수정하기 쉽게 만든다.
4.  같은 디자인을 반복 적용할 수 있도록 템플릿을 제공한다.
5.  AI API 없이도 핵심 편집 기능이 독립적으로 작동하도록 한다.
6.  처음부터 복잡하게 만들지 말고 MVP부터 완성한 뒤 확장한다.
